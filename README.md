# Portfolio website

This is a static portfolio site with no build step.

## Deploy to Vercel

1. Import this repository in Vercel.
2. Leave the framework preset set to **Other**.
3. Leave the build command and output directory empty, then deploy.

`vercel.json` maps the site root (`/`) to `portfolio_v2.html`, so the portfolio opens at the deployed domain without renaming the original file.
